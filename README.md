# frik

A Wayland-exclusive screenshot tool that extracts text from your screenshot

# Prerequisites:

- grim
- tesseract packages and language data or smth

## Installation

pip
```bash
pip install frik
```

uv
```bash
uv tool install pitt
```

## Usage

There's really only one way to use it:

```bash
frik
```
